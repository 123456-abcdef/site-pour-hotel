# Mbouoh Star Palace – Dschang

Site vitrine de l'hôtel **Mbouoh Star Palace** à Dschang (Cameroun).

## Contenu

- `index.html` : page unique du site (HTML autonome, styles Tailwind via CDN, images intégrées).

## Déploiement

Le site est hébergé sur Netlify : https://hotelmbouohstarpalace.netlify.app

Aucune étape de build n'est nécessaire : chaque push sur la branche `main` publie automatiquement `index.html` à la racine du site.
